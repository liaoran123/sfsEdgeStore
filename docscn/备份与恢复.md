# 备份与恢复

数据备份与恢复操作指南。

## 备份

### 通过 API

```bash
curl -X POST "http://localhost:8081/api/backup?path=./backups"
```

响应：
```json
{
  "status": "success",
  "backupFile": "./backups/backup_2024-01-01_12-00-00.db"
}
```

### 通过脚本

Linux：
```bash
./scripts/backup.sh
```

Windows：
```powershell
.\scripts\backup.ps1
```

## 恢复

### 通过 API

```bash
curl -X POST "http://localhost:8081/api/restore?file=./backups/backup_2024-01-01_12-00-00.db"
```

响应：
```json
{
  "status": "success",
  "message": "Database restored successfully"
}
```

## 自动备份

在配置中启用自动备份：

```json
{
  "enable_auto_backup": true,
  "backup_interval_hours": 24,
  "backup_path": "./backups",
  "max_backup_count": 7
}
```

## 备份策略

| 场景 | 频率 | 保留时间 |
|------|------|---------|
| 生产环境 | 每天 | 7 天 |
| 开发环境 | 每周 | 4 周 |
| 测试环境 | 手动 | 按需 |

## 最佳实践

1. **定期备份** - 设置自动每日备份
2. **异地存储** - 将备份复制到独立位置
3. **测试恢复** - 定期验证备份完整性
4. **监控备份大小** - 确保磁盘空间充足
