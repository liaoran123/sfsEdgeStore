# 监控与告警

监控 sfsEdgeStore 运行状态并配置告警。

## 指标

### Prometheus 指标

在配置中启用 Prometheus 指标：

```json
{
  "enable_prometheus": true,
  "prometheus_path": "/metrics"
}
```

访问指标：
```bash
curl http://localhost:8081/metrics
```

### 系统状态

```bash
curl http://localhost:8081/api/status
```

### 资源使用情况

```bash
curl http://localhost:8081/api/resources/status
```

## 资源监控

sfsEdgeStore 内置资源监控，每 30 秒运行一次。

### 配置

```json
{
  "enable_resource_monitoring": true,
  "max_memory_mb": 512,
  "max_cpu_percent": 80,
  "resource_monitor_interval_seconds": 30
}
```

### 告警

当超过阈值时，通过配置的通知渠道触发告警。

## 告警配置

### 启用告警

```json
{
  "enable_alert_notifications": true,
  "alert_notification_channels": ["mqtt", "webhook"],
  "alert_mqtt_topic": "sfsEdgeStore/alerts",
  "alert_webhook_url": "https://hooks.example.com/alerts",
  "alert_min_severity": "warning"
}
```

### 通知渠道

| 渠道 | 配置项 | 说明 |
|------|--------|------|
| MQTT | `alert_mqtt_topic` | 发布告警到 MQTT 主题 |
| Webhook | `alert_webhook_url` | 发送 HTTP POST 到 Webhook |

### 严重级别

- `info` - 信息
- `warning` - 警告
- `error` - 错误
- `critical` - 严重

### 测试告警

```bash
curl -X POST http://localhost:8081/api/alerts/test
```

### 查看告警

```bash
# 所有告警
curl http://localhost:8081/api/alerts

# 分组告警
curl http://localhost:8081/api/alert-groups
```

### 告警通知器状态

```bash
curl http://localhost:8081/api/alerts/notifier/status
```

## 设备监控

sfsEdgeStore 自动监控设备健康状态。

### 离线检测

通过 `device_offline_threshold_seconds` 配置（默认 300 秒）。

### 数据异常检测

基于 `data_anomaly_threshold_percent` 检测异常数据模式。

### 趋势分析

当达到最小点数（`data_trend_min_points`）时分析数据趋势。

## 订阅监控

### 检查订阅状态

```bash
curl http://localhost:8081/api/subscription/status
```

### 测试订阅

```bash
curl -X POST http://localhost:8081/api/subscription/test
```

### 查看已订阅主题
