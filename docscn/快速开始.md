# 快速开始

5 分钟让 sfsEdgeStore 运行起来。

## 前置条件

- Go 1.21 或更高版本（源码编译需要）
- MQTT Broker（如 Mosquitto）
- EdgeX Foundry（可选，用于真实数据源）

## 步骤 1：获取代码

```bash
git clone https://github.com/liaoran123/sfsEdgeStore.git
cd sfsEdgeStore
```

## 步骤 2：编译

```bash
go build -ldflags="-s -w" -o sfsedgestore .
```

## 步骤 3：运行

```bash
./sfsedgestore
```

sfsEdgeStore 使用智能默认配置，无需任何配置即可启动：

| 配置项 | 默认值 |
|---------|-------|
| MQTT Broker | `tcp://localhost:1883` |
| MQTT Topic | `edgex/events/core/#` |
| HTTP Port | `8081` |
| Database Path | `data/sfs.db` |

## 步骤 4：验证

```bash
# 健康检查
curl http://localhost:8081/health

# 查看指标
curl http://localhost:8081/metrics
```

## 步骤 5：查询数据

```bash
# 查询所有数据
curl http://localhost:8081/api/readings

# 按设备查询
curl "http://localhost:8081/api/readings?deviceName=Device001&limit=10"
```
