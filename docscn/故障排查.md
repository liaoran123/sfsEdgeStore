# 故障排查

sfsEdgeStore 常见问题与解决方案。

## MQTT 连接问题

### 连接被拒绝

**现象：** MQTT 客户端无法连接到 Broker。

**检查清单：**
1. 确认 MQTT Broker 正在运行：
   ```bash
   mosquitto -v
   ```
2. 检查配置中的 Broker 地址：
   ```json
   "mqtt_broker": "tcp://localhost:1883"
   ```
3. 验证网络连通性：
   ```bash
   telnet localhost 1883
   ```
4. 检查认证凭据（如果需要）：
   ```json
   "mqtt_username": "user",
   "mqtt_password": "password"
   ```

### TLS 连接失败

**现象：** MQTT TLS 握手失败。

**检查清单：**
1. 确认证书文件存在且可读：
   ```bash
   ls -la /etc/ssl/certs/ca.pem
   ls -la /etc/ssl/certs/server.pem
   ls -la /etc/ssl/private/server.key
   ```
2. 检查证书有效性：
   ```bash
   openssl x509 -in /etc/ssl/certs/server.pem -text -noout
   ```

### 未收到数据

**现象：** 已连接但没有存储读数。

**检查清单：**
1. 确认主题订阅与 EdgeX 发布匹配：
   ```bash
   curl http://localhost:8081/api/subscription/status
   ```
2. 使用示例 EdgeX 负载测试：
   ```bash
   curl -X POST http://localhost:8081/api/test-edgex -d @sample_edgex_payload.json
   ```
3. 检查设备配置与传入数据格式是否匹配

## 数据库问题

### 数据库初始化失败

**现象：** 应用退出并显示数据库错误。

**检查清单：**
1. 验证目录权限：
   ```bash
   ls -la data/
   ```
2. 检查磁盘空间：
   ```bash
   df -h
   ```
3. 尝试清除损坏的数据库：
   ```bash
   rm -rf data/
   ```

### 磁盘空间已满

**现象：** 数据库写入失败。

**解决方案：**
1. 检查数据保留策略：
   ```bash
   curl http://localhost:8081/api/retention/status
   ```
2. 手动触发清理：
   ```bash
   curl -X POST http://localhost:8081/api/retention/cleanup
   ```
3. 在配置中启用自动保留策略

## 内存问题

### 内存使用过高

**现象：** 内存超过配置限制。

**解决方案：**
1. 检查当前资源使用：
   ```bash
   curl http://localhost:8081/api/resources/status
   ```
2. 调整配置中的内存限制：
   ```json
   "max_memory_mb": 512
   ```
3. 审查数据保留策略以防止数据累积
4. 考虑降低分析引擎内存使用：
   ```json
   "analyzer_max_memory": 128
   ```

## HTTP 服务器问题

### 端口已被占用

**现象：** HTTP 服务器无法启动。

**解决方案：**
1. 检查端口占用情况：
   ```bash
   # Linux
   lsof -i :8081
   # Windows
   netstat -ano | findstr :8081
   ```
2. 在配置中更改 HTTP 端口：
   ```json
   "http_port": "8082"
   ```

### HTTPS 证书错误

**现象：** HTTPS 服务器无法启动。

**检查清单：**
1. 验证证书和密钥路径是否正确
2. 检查证书/密钥格式：
   ```bash
   openssl x509 -in server.pem -text -noout
   openssl rsa -in server.key -check
   ```
3. 确保密钥与证书匹配

## 性能问题

### 查询响应慢

**解决方案：**
1. 为工作负载使用合适的数据库场景
2. 启用数据保留以限制数据大小
3. 在查询中使用时间范围过滤：
   ```bash
   curl "http://localhost:8081/api/readings?deviceName=Device001&startTime=2024-01-01T00:00:00Z&endTime=2024-01-02T00:00:00Z"
   ```
4. 使用 limit 参数限制结果大小

### CPU 使用率过高

**解决方案：**
1. 如果不需要，禁用分析引擎：
   ```json
   "enable_analyzer": false
   ```
2. 降低监控频率
3. 检查是否有告警风暴导致过多通知

## 日志查看

### 查看日志

```bash
# Linux systemd
journalctl -u sfsedgestore -n 100

# Docker
docker logs sfsedgestore --tail 100

# 直接执行
./sfsedgestore 2>&1 | tee sfsedgestore.log
```

### 启用详细日志

使用 debug 输出运行：
```bash
export GODEBUG=1
./sfsedgestore
```
