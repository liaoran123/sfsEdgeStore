# sfsEdgeStore 文档

轻量级工业物联网边缘数据存储适配器，专为 EdgeX Foundry 设计。

## 数据主权与合规

**sfsEdgeStore 以数据主权为核心设计理念。** 所有数据存储在本地边缘设备上——不依赖云端，不向第三方传输数据。

- **GDPR 合规**：数据永不离开您的设备，无跨境数据传输
- **本地优先架构**：完全离线运行，可选、可控的同步机制
- **静态数据加密**：AES-256 数据库加密，没有您的密钥数据无法读取
- **零供应商锁定**：纯 Go 二进制文件、嵌入式数据库，无需外部服务

这使得 sfsEdgeStore 非常适合对数据驻留有严格要求的行业：制造业、能源、医疗和关键基础设施。
