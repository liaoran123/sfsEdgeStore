# 系统架构

sfsEdgeStore 系统架构概览。

## 轻量级边缘架构

```
┌─────────────────────────────────────────────────────────────┐
│                      边缘节点（资源受限）                     │
│                                                             │
│  ┌───────────────────────────────────────────────────────┐ │
│  │              EdgeX Foundry                              │ │
│  │  （数据采集、设备管理）                                  │ │
│  └────────────────────┬──────────────────────────────────┘ │
│                       │ MQTT                              │
│                       ▼                                   │
│  ┌───────────────────────────────────────────────────────┐ │
│  │         sfsEdgeStore（轻量级适配器）                     │ │
│  │  ┌──────────────┐  ┌──────────────┐  ┌──────────┐  │ │
│  │  │  MQTT 客户端  │→ │  数据队列    │→ │  sfsDb   │  │ │
│  │  └──────────────┘  └──────────────┘  └──────────┘  │ │
│  │  ┌──────────────┐  ┌──────────────┐                  │ │

│                       │ HTTP API                         │
└───────────────────────┼─────────────────────────────────────┘
                        ▼
                  外部查询/监控
```

## 核心组件

### 1. MQTT 客户端（`core/mqtt/`）

订阅 EdgeX Foundry 事件主题，接收物联网传感器数据。

- 协议：MQTT 3.1.1/5.0
- 支持 TLS 双向认证
- 自动重连，可配置超时时间
- 主题模式匹配（`edgex/events/#`）

### 2. 数据队列（`queue/`）

MQTT 数据接入与数据库存储之间的可靠消息缓冲。

- 基于嵌入式存储的持久化队列
- 失败自动重试（最多 3 次）
- 重启后数据不丢失
- 背压处理

### 3. 数据库（`core/database/`）

使用 sfsDb（LevelDB 封装）高效存储数据。

- 嵌入式，零外部依赖
- WAL（预写日志）保证崩溃安全
- 支持压缩和可选加密
- 多种性能场景（embedded、IoT、edge、game）

### 4. HTTP 服务器（`server/`）

用于数据查询和系统管理的 RESTful API。

- 健康检查端点
- 数据查询（支持设备、时间范围、数量过滤）
- 备份和恢复操作
- WebSocket 实时数据流
- Prometheus 指标导出

### 5. 监控系统（`monitor/`）

系统指标收集和告警。

- MQTT 连接状态跟踪
- HTTP 请求计数
- 设备监控与离线检测
- 过期告警自动清理

### 6. 告警系统（`alert/`）

基于阈值的告警，支持多种通知渠道。

- MQTT 主题发布
- Webhook 集成
- 可配置严重级别
- 告警自动过期

### 7. 分析引擎（`analyzer/`）

用于异常检测和趋势分析的数据分析引擎。

- 按设备/读数配置阈值
- 低频率运行（资源占用极小）
- 基于时间的趋势分析

### 8. 资源监控（`resource/`）

系统资源跟踪与保护。

- 内存使用监控
- CPU 使用跟踪
- 可配置阈值告警

### 9. 数据保留（`retention/`）

自动清理过期数据。

- 可配置保留周期
- 批量处理提高效率
- 低频定时执行

### 10. 数据同步（`cloudsync/sync/`）（企业版）

分布式部署的云同步功能。

- 令牌桶限流
- 持久化同步队列
- 自动重试，可配置间隔

## 设计原则

1. **小而美** - 只做一件事，做到极致
2. **边缘优先** - 所有功能优先考虑边缘场景
3. **数据主权** - 数据留在本地，不依赖云端，无跨境传输
4. **零依赖** - 仅依赖 sfsDb，无重型组件
5. **高可用** - 断电恢复、数据重试、本地存储

### 为什么本地优先很重要

与基于云的物联网解决方案不同，sfsEdgeStore 将所有数据存储在边缘设备上：

- **GDPR 合规**：数据永不离开您的场所
- **欧盟《网络弹性法案》**：不依赖外部服务
- **零数据泄漏风险**：无遥测、无分析数据发送到第三方
- **离线工作**：无需互联网连接即可完全运行
- **成本可预测**：无云存储或带宽费用
