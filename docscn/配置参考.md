# 配置参考

sfsEdgeStore 完整配置说明。

## 配置方式（优先级从高到低）

1. **环境变量**（最高优先级）
2. **配置文件**（`config.json`）
3. **默认值**

## 配置文件

在应用根目录创建 `config.json`。

## 常用配置（从这里开始）

大多数客户只需要自定义几个关键设置。以下是按优先级排列的最常修改的配置。

### 必改项（几乎每个部署都需要改）

| 配置项 | 默认值 | 典型值 | 为什么要改 |
|--------|--------|--------|-----------|
| `mqtt_broker` | `tcp://localhost:1883` | 你的 MQTT 服务器地址 | 每个客户的 MQTT Broker 地址不同 |
| `mqtt_topic` | `edgex/events/#` | 客户的 EdgeX 主题 | 主题模式因部署而异 |
| `db_path` | `data/sfs.db` | `/var/lib/sfsedgestore/data/sfs.db` | 生产环境通常需要固定存储路径 |
| `http_port` | `8081` | 可用端口 | 可能与现有服务端口冲突 |

### 常改项（资源受限或合规需求）

| 配置项 | 默认值 | 为什么要改 |
|--------|--------|-----------|
| `enable_retention_policy` + `retention_days` | `false` / `30` | 边缘设备磁盘有限，需控制数据量 |
| `db_scenario` | `edge` | 根据硬件性能选择合适的场景（embedded/IoT/edge/game） |
| `enable_resource_monitoring` + `max_memory_mb` | `false` / `45` | 资源受限设备需要调整 |
| `db_use_encryption` + `db_encryption_key` | `false` | GDPR 合规、医疗等受监管行业 |

### 高级项（企业版/特殊场景）

| 配置项 | 默认值 | 为什么要改 |
|--------|--------|-----------|
| `mqtt_use_tls` + 证书路径 | `false` | 需要安全传输 |
| `http_use_tls` + 证书路径 | `false` | 外部访问需要 HTTPS |
| `enable_data_sync` | `false` | 企业版云端同步功能 |
| `enable_alert_notifications` | `false` | 需要通过 MQTT/Webhook 告警 |
| `enable_prometheus` | `false` | 集成 Prometheus 监控 |
| `custom_topics` | `[]` | 需要订阅多个自定义主题 |

### 几乎不改（默认值即可）

| 配置项 | 为什么不改 |
|--------|-----------|
| `client_id` | 自动带时间戳生成 |
| `analyzer_*` 参数 | 默认值已优化 |
| `simulator_*` 参数 | 仅开发/测试使用 |
| `cleanup_batch_size` | 1000 对大多数情况足够 |
| `connection_timeout` / `keep_alive` | 默认值通用 |

### 快速上手示例

生产环境的最小配置：

```json
{
  "mqtt_broker": "tcp://192.168.1.100:1883",
  "mqtt_topic": "edgex/events/#",
  "db_path": "/var/lib/sfsedgestore/data/sfs.db",
  "http_port": "8081",
  "enable_retention_policy": true,
  "retention_days": 30
}
```

## 核心配置

| 配置项 | 类型 | 环境变量 | 默认值 | 说明 |
|--------|------|----------|--------|------|
| `db_path` | string | `EDGEX_DB_PATH` | `data/sfs.db` | 数据库存储路径 |
| `mqtt_broker` | string | `EDGEX_MQTT_BROKER` | `tcp://localhost:1883` | MQTT 服务器地址 |
| `mqtt_topic` | string | `EDGEX_MQTT_TOPIC` | `edgex/events/#` | MQTT 订阅主题 |
| `client_id` | string | `EDGEX_CLIENT_ID` | `sfsdb-edgex-adapter` | MQTT 客户端 ID |
| `http_port` | string | `EDGEX_HTTP_PORT` | `8081` | HTTP 服务端口 |
| `auto_subscribe` | bool | `EDGEX_AUTO_SUBSCRIBE` | `true` | 自动订阅 MQTT 主题 |
| `dev_config_path` | string | `EDGEX_DEV_CONFIG_PATH` | - | 设备配置路径 |

## 数据库配置

| 配置项 | 类型 | 环境变量 | 默认值 | 说明 |
|--------|------|----------|--------|------|
| `db_use_encryption` | bool | `EDGEX_DB_USE_ENCRYPTION` | `false` | 启用数据库加密 |
| `db_encryption_key` | string | `EDGEX_DB_ENCRYPTION_KEY` | - | 加密密钥 |
| `db_encryption_algorithm` | string | `EDGEX_DB_ENCRYPTION_ALGORITHM` | `AES-256-GCM` | 加密算法 |
| `db_scenario` | string | `EDGEX_DB_SCENARIO` | `edge` | 数据库场景：`embedded`、`iot`、`edge`、`game`、`default` |

### 数据库场景

| 场景 | 写缓冲 | 块缓存 | 适用场景 |
|------|--------|--------|----------|
| `embedded` | 2MB | 4MB | 嵌入式设备 |
| `iot` | 4MB | 8MB | IoT 设备 |
| `edge`（默认） | 16MB | 32MB | 边缘计算 |
| `game` | 64MB | 128MB | 游戏场景 |
| `default` | 8MB | 16MB | 通用场景 |
