# 安装指南

sfsEdgeStore 完整安装指南。

## 支持平台

| 平台 | 架构 | 状态 |
|------|------|------|
| Linux | amd64 | 官方支持 |
| Linux | arm64 | 官方支持 |
| Linux | armv7 (树莓派) | 官方支持 |
| Windows | amd64 | 官方支持 |
| macOS | amd64/arm64 | 社区支持 |

## 系统要求

| 资源 | 最低要求 | 推荐配置 |
|------|---------|---------|
| CPU | 1 核 | 2 核以上 |
| 内存 | 128 MB | 256 MB 以上 |
| 磁盘 | 1 GB | 2 GB 以上 |

## 方式一：源码编译

```bash
# 克隆仓库
git clone https://github.com/liaoran123/sfsEdgeStore.git
cd sfsEdgeStore

# 编译
go build -ldflags="-s -w" -o sfsedgestore .

# 运行
./sfsedgestore
```

## 方式二：二进制发布包

从 [GitHub Releases](https://github.com/liaoran123/sfsEdgeStore/releases) 下载：

```bash
# Linux amd64
wget https://github.com/liaoran123/sfsEdgeStore/releases/latest/download/sfsedgestore-linux-amd64.tar.gz
tar -xzf sfsedgestore-linux-amd64.tar.gz
sudo mv sfsedgestore /usr/local/bin/

# 运行
sfsedgestore
```

## 方式三：Docker 部署

```bash
docker run -d \
  --name sfsedgestore \
  -p 8081:8081 \
  -v ./data:/app/data \
  -v ./config.json:/app/config.json \
  liaoran123/sfsedgestore:latest
```

## 方式四：Linux 系统服务

### 1. 创建 systemd 服务文件

```ini
[Unit]
Description=sfsEdgeStore 物联网数据适配器
After=network.target mosquitto.service

[Service]
Type=simple
User=sfsedgestore
WorkingDirectory=/opt/sfsedgestore
ExecStart=/opt/sfsedgestore/sfsedgestore
Restart=on-failure
RestartSec=10
MemoryLimit=256M
CPUQuota=50%

[Install]
WantedBy=multi-user.target
```

### 2. 安装并启动

```bash
sudo systemctl daemon-reload
sudo systemctl enable sfsedgestore
sudo systemctl start sfsedgestore
sudo systemctl status sfsedgestore
```

## 验证安装

```bash
# 健康检查
curl http://localhost:8081/health

# 预期响应
{"status":"healthy","timestamp":1234567890}
```
