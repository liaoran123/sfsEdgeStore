# 边缘计算与脚本引擎

## 1. 概述

边缘计算与脚本引擎是 sfsEdgeStore 企业版的核心功能之一，旨在解决工业现场数据“脏”的问题。通过 Lua 或 JavaScript 脚本引擎，用户可以在边缘端对采集到的数据进行实时处理和转换，减少云端处理压力，提高数据处理效率。同时，边缘报警功能可以在边缘端直接判断异常情况，及时触发报警，无需经过云端。

## 2. 核心功能

### 2.1 脚本引擎

sfsEdgeStore 支持 Lua 或 JavaScript 脚本引擎，允许用户在 `devices.yaml` 中挂载自定义脚本，对采集到的数据进行处理和转换。

**支持的脚本语言：**
- **Lua**：轻量级脚本语言，适合资源受限的边缘设备
- **JavaScript**：广泛使用的脚本语言，学习曲线较低

**配置示例：**
```yaml
- name: "temp-sensor"
  driver: "modbus"
  transform: |
    # 用户自定义脚本
    value = raw_value / 10.0
    if value > 50.0 then status = "HIGH" else status = "OK" end
    return { value=value, status=status }
```

### 2.2 边缘报警

在边缘端直接判断异常情况，及时触发本地报警或推送消息，不需要经过云端。

**报警类型：**
- **阈值报警**：当数据超过设定的阈值时触发
- **趋势报警**：当数据变化趋势异常时触发
- **状态报警**：当设备状态异常时触发

**配置示例：**
```yaml
- name: "temp-sensor"
  driver: "modbus"
  transform: |
    value = raw_value / 10.0
    return { value=value }
  alerts:
    - name: "high-temperature"
      condition: "value > 100"
      message: "温度过高"
      actions:
        - type: "local"
          command: "echo 'Temperature alert' > /tmp/alert.log"
        - type: "mqtt"
          topic: "sfsEdgeStore/alerts"
          payload: "{\"device\": \"temp-sensor\", \"message\": \"温度过高\"}"
```

## 3. 实现细节

### 3.1 脚本引擎实现

使用 Go 语言的 `github.com/yuin/gopher-lua` 包实现 Lua 脚本引擎，或使用 `github.com/dop251/goja` 包实现 JavaScript 脚本引擎。

**核心代码示例：**
```go
// script.go
package script

import (
	"github.com/yuin/gopher-lua"
)

// ScriptEngine 脚本引擎接口
type ScriptEngine interface {
	Execute(script string, data map[string]interface{}) (map[string]interface{}, error)
}

// LuaEngine Lua 脚本引擎
type LuaEngine struct {
	L *lua.LState
}

// NewLuaEngine 创建 Lua 脚本引擎
func NewLuaEngine() *LuaEngine {
	return &LuaEngine{
		L: lua.NewState(),
	}
}

// Execute 执行 Lua 脚本
func (e *LuaEngine) Execute(script string, data map[string]interface{}) (map[string]interface{}, error) {
	// 设置全局变量
	for k, v := range data {
		switch val := v.(type) {
		case float64:
			e.L.SetGlobal(k, lua.LNumber(val))
		case string:
			e.L.SetGlobal(k, lua.LString(val))
		case bool:
			e.L.SetGlobal(k, lua.LBool(val))
		}
	}

	// 执行脚本
	if err := e.L.DoString(script); err != nil {
		return nil, err
	}

	// 获取返回值
	result := make(map[string]interface{})
	if val := e.L.GetGlobal("value"); val != lua.LNil {
		if num, ok := val.(lua.LNumber); ok {
			result["value"] = float64(num)
		} else if str, ok := val.(lua.LString); ok {
			result["value"] = string(str)
		} else if b, ok := val.(lua.LBool); ok {
			result["value"] = bool(b)
		}
	}

	if val := e.L.GetGlobal("status"); val != lua.LNil {
		if str, ok := val.(lua.LString); ok {
			result["status"] = string(str)
		}
	}

	return result, nil
}

// Close 关闭脚本引擎
func (e *LuaEngine) Close() {
	e.L.Close()
}
```

### 3.2 边缘报警实现

实现边缘报警功能，包括条件判断和报警触发：

**核心代码示例：**
```go
// alert.go
package alert

import (
	"fmt"
	"os/exec"
	"sfsEdgeStore/core/mqtt"
)

// Alert 报警配置
type Alert struct {
	Name      string   `yaml:"name"`
	Condition string   `yaml:"condition"`
	Message   string   `yaml:"message"`
	Actions   []Action `yaml:"actions"`
}

// Action 报警动作
type Action struct {
	Type    string `yaml:"type"`    // local, mqtt
	Command string `yaml:"command"` // 本地命令
	Topic   string `yaml:"topic"`   // MQTT 主题
	Payload string `yaml:"payload"` // MQTT 消息
}

// CheckAlert 检查是否触发报警
func CheckAlert(alert Alert, data map[string]interface{}) bool {
	// 这里简化实现，实际应该使用表达式解析器
	// 例如使用 github.com/Knetic/govaluate 包
	return false
}

// TriggerAlert 触发报警
func TriggerAlert(alert Alert, data map[string]interface{}) error {
	for _, action := range alert.Actions {
		switch action.Type {
		case "local":
			// 执行本地命令
			cmd := exec.Command("sh", "-c", action.Command)
			if err := cmd.Run(); err != nil {
				return fmt.Errorf("执行本地命令失败: %v", err)
			}
		case "mqtt":
			// 发送 MQTT 消息
			if err := mqtt.Publish(action.Topic, action.Payload); err != nil {
				return fmt.Errorf("发送 MQTT 消息失败: %v", err)
			}
		}
	}
	return nil
}
```

## 4. 配置与使用

### 4.1 配置文件

在 `devices.yaml` 文件中配置脚本和报警：

```yaml
devices:
  - name: "temp-sensor"
    driver: "modbus"
    address: "192.168.1.100:502"
    register: 0
    transform: |
      # Lua 脚本
      value = raw_value / 10.0
      if value > 50.0 then status = "HIGH" else status = "OK" end
      return { value=value, status=status }
    alerts:
      - name: "high-temperature"
        condition: "value > 100"
        message: "温度过高"
        actions:
          - type: "local"
            command: "echo 'Temperature alert' > /tmp/alert.log"
          - type: "mqtt"
            topic: "sfsEdgeStore/alerts"
            payload: "{\"device\": \"temp-sensor\", \"message\": \"温度过高\"}"
```

### 4.2 命令行工具

使用 `sfs-cli` 命令行工具管理脚本和报警：

```bash
# 测试脚本
sfs-cli script test --script "value = raw_value / 10.0; return { value=value }" --data "{\"raw_value\": 1000}"

# 查看报警状态
sfs-cli alert list

# 手动触发报警
sfs-cli alert trigger --name "high-temperature"
```

## 5. 最佳实践

1. **脚本优化**：保持脚本简洁，避免复杂计算，减少资源消耗
2. **报警阈值设置**：根据实际情况设置合理的报警阈值
3. **报警动作设计**：根据需要设计合适的报警动作，如本地通知、MQTT 消息等
4. **脚本测试**：在部署前测试脚本的正确性
5. **错误处理**：在脚本中添加错误处理，确保脚本执行稳定

## 6. 总结

边缘计算与脚本引擎是 sfsEdgeStore 企业版的重要功能，通过在边缘端对数据进行实时处理和转换，减少了云端处理压力，提高了数据处理效率。同时，边缘报警功能可以在边缘端直接判断异常情况，及时触发报警，无需经过云端，提高了系统的响应速度。

这些功能使 sfsEdgeStore 不仅仅是一个数据采集工具，更是一个智能的数据处理平台，为工业物联网应用提供了更强大的支持。
