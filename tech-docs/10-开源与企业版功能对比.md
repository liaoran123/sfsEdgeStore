# 开源与企业版功能对比

## 1. 概述

sfsEdgeStore 采用 Open Core 商业模式，核心功能完全开源，企业版提供高级功能。这种模式既保证了产品的安全性和可靠性，又为用户提供了灵活的选择空间。

## 2. 功能对比

### 2.1 开源版功能

| 模块 | 功能 | 描述 |
|------|------|------|
| **连接层** | Modbus/MQTT/OPC 采集 | 支持多种协议的数据采集 |
| **存储层** | 本地 SQLite/LevelDB | 轻量级本地数据存储 |
| **同步层** | 基础数据同步 | 基本的数据同步功能 |
| **运维层** | 基础配置管理 | 基本的配置管理功能 |
| **安全层** | 基础安全措施 | 基本的安全防护 |
| **计算层** | 基础数据处理 | 基本的数据处理功能 |
| **展示层** | 基础 Web 界面 | 基本的 Web 监控界面 |

### 2.2 企业版功能

| 模块 | 功能 | 描述 |
|------|------|------|
| **连接层** | 高级协议支持 | 支持更多工业协议 |
| **存储层** | 高级存储优化 | 更高效的数据存储和查询 |
| **同步层** | 断点续传、双向同步 | 确保数据不丢失 |
| **运维层** | 远程批量控制、配置版本控制 | 提高运维效率 |
| **安全层** | TLS 加密、防火墙、密钥管理 | 企业级安全保障 |
| **计算层** | 边缘脚本、边缘报警 | 智能数据处理 |
| **展示层** | 高级可视化监控大屏 | 更丰富的数据分析和展示 |
| **云服务** | 云端同步、远程监控 | 实现云边协同 |

## 3. 商业模式

### 3.1 开源策略

- **核心功能开源**：sfsDb 引擎、基础读写接口、EdgeX 适配器等核心功能完全开源
- **免费使用**：任何人都可以免费使用开源版功能，无限制
- **社区驱动**：鼓励社区贡献和反馈，共同改进产品

### 3.2 企业版策略

- **高级功能收费**：云同步、可视化监控、高级运维等企业级功能收费
- **专业支持**：提供技术支持、培训和咨询服务
- **定制化开发**：根据客户需求进行定制化开发

### 3.3 定价策略

- **开源版**：免费
- **企业版**：根据功能模块和部署规模定价
  - 基础企业版：￥1,999/年
  - 高级企业版：￥4,999/年
  - 企业定制版：根据需求报价

## 4. 迁移路径

### 4.1 从开源版到企业版

1. **评估需求**：根据业务需求评估是否需要企业版功能
2. **购买许可证**：联系销售团队购买企业版许可证
3. **升级安装**：使用企业版安装包升级现有系统
4. **配置迁移**：迁移现有配置到企业版
5. **功能启用**：启用企业版高级功能

### 4.2 企业版优势

- **更高级的安全保障**：TLS 加密、防火墙等企业级安全功能
- **更强大的运维能力**：远程批量控制、配置版本控制等
- **更智能的数据处理**：边缘脚本、边缘报警等
- **更丰富的可视化**：高级监控大屏
- **更可靠的云同步**：断点续传、双向同步
- **专业技术支持**：7x24 小时技术支持

## 5. 总结

sfsEdgeStore 的 Open Core 商业模式为用户提供了灵活的选择：

- **对于小团队和个人开发者**：可以使用开源版，享受免费的核心功能
- **对于企业用户**：可以升级到企业版，获得更高级的功能和专业支持

这种模式不仅保证了产品的安全性和可靠性，也为项目的可持续发展提供了资金支持，实现了用户和开发者的双赢。
