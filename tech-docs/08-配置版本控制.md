# 配置版本控制

## 1. 概述

配置版本控制是 sfsEdgeStore 企业版的核心功能之一，旨在解决配置变更管理的问题。通过 Git 风格的配置回滚机制，每次配置变更都会被自动备份，当配置出现问题时，可以快速回滚到之前的版本，为运维人员提供一颗“后悔药”。

## 2. 核心功能

### 2.1 配置备份

sfsEdgeStore 会自动备份每次配置变更，包括本地修改和远程下发的配置。

**备份方式：**
- **文件备份**：每次配置变更时，自动备份旧的 `devices.yaml` 文件
- **版本树**：在内部维护一个配置版本树，记录所有配置变更历史

### 2.2 一键回滚

提供命令行工具，支持一键回滚到指定版本的配置。

**使用示例：**
```bash
# 回滚到版本 1
sfs-cli config rollback --to version=1

# 回滚到上一个版本
sfs-cli config rollback --to previous
```

### 2.3 版本管理

支持查看配置版本历史，比较不同版本的配置差异。

**使用示例：**
```bash
# 查看版本历史
sfs-cli config history

# 比较版本差异
sfs-cli config diff --from version=1 --to version=2
```

## 3. 实现细节

### 3.1 配置备份实现

**核心代码示例：**
```go
// config.go
package config

import (
	"fmt"
	"os"
	"path/filepath"
	"time"
)

// BackupConfig 备份配置文件
func BackupConfig(configFile string) error {
	// 读取当前配置
	data, err := os.ReadFile(configFile)
	if err != nil {
		return fmt.Errorf("读取配置文件失败: %v", err)
	}

	// 创建备份目录
	backupDir := filepath.Join(filepath.Dir(configFile), "backups")
	if err := os.MkdirAll(backupDir, 0755); err != nil {
		return fmt.Errorf("创建备份目录失败: %v", err)
	}

	// 生成备份文件名
	timestamp := time.Now().Format("20060102150405")
	backupFile := filepath.Join(backupDir, fmt.Sprintf("devices_%s.yaml", timestamp))

	// 写入备份文件
	if err := os.WriteFile(backupFile, data, 0644); err != nil {
		return fmt.Errorf("写入备份文件失败: %v", err)
	}

	return nil
}
```

### 3.2 版本管理实现

**核心代码示例：**
```go
// version.go
package config

import (
	"fmt"
	"os"
	"path/filepath"
	"sort"
	"strings"
	"time"
)

// ConfigVersion 配置版本
type ConfigVersion struct {
	Version   int
	Timestamp time.Time
	Filepath  string
}

// GetConfigVersions 获取配置版本列表
func GetConfigVersions(backupDir string) ([]ConfigVersion, error) {
	// 读取备份目录
	files, err := os.ReadDir(backupDir)
	if err != nil {
		return nil, fmt.Errorf("读取备份目录失败: %v", err)
	}

	// 解析版本文件
	var versions []ConfigVersion
	for i, file := range files {
		if !file.IsDir() && strings.HasPrefix(file.Name(), "devices_") && strings.HasSuffix(file.Name(), ".yaml") {
			// 解析时间戳
			timestampStr := strings.TrimSuffix(strings.TrimPrefix(file.Name(), "devices_"), ".yaml")
			timestamp, err := time.Parse("20060102150405", timestampStr)
			if err != nil {
				continue
			}

			versions = append(versions, ConfigVersion{
				Version:   i + 1,
				Timestamp: timestamp,
				Filepath:  filepath.Join(backupDir, file.Name()),
			})
		}
	}

	// 按时间排序
	sort.Slice(versions, func(i, j int) bool {
		return versions[i].Timestamp.Before(versions[j].Timestamp)
	})

	return versions, nil
}

// RollbackConfig 回滚配置
func RollbackConfig(configFile string, version int) error {
	// 获取备份目录
	backupDir := filepath.Join(filepath.Dir(configFile), "backups")

	// 获取版本列表
	versions, err := GetConfigVersions(backupDir)
	if err != nil {
		return err
	}

	// 检查版本是否存在
	if version < 1 || version > len(versions) {
		return fmt.Errorf("版本不存在")
	}

	// 读取备份文件
	backupFile := versions[version-1].Filepath
	data, err := os.ReadFile(backupFile)
	if err != nil {
		return fmt.Errorf("读取备份文件失败: %v", err)
	}

	// 写入配置文件
	if err := os.WriteFile(configFile, data, 0644); err != nil {
		return fmt.Errorf("写入配置文件失败: %v", err)
	}

	return nil
}
```

## 4. 配置与使用

### 4.1 配置文件

在 `config.yaml` 文件中配置版本控制选项：

```yaml
# 版本控制配置
version_control:
  enabled: true
  backup_dir: "./backups"
  max_backups: 10  # 最大备份数量
```

### 4.2 命令行工具

使用 `sfs-cli` 命令行工具管理配置版本：

```bash
# 查看版本历史
sfs-cli config history

# 回滚到指定版本
sfs-cli config rollback --to version=1

# 比较版本差异
sfs-cli config diff --from version=1 --to version=2

# 清理旧备份
sfs-cli config clean --keep=5
```

## 5. 最佳实践

1. **定期备份**：确保配置变更时自动备份
2. **版本命名**：为重要版本添加描述性标签
3. **差异比较**：在回滚前比较版本差异，确保回滚操作的正确性
4. **备份清理**：定期清理旧备份，避免占用过多存储空间
5. **权限控制**：限制配置修改权限，避免误操作

## 6. 总结

配置版本控制是 sfsEdgeStore 企业版的重要功能，通过 Git 风格的配置回滚机制，为运维人员提供了一种安全、可靠的配置管理方式。当配置出现问题时，可以快速回滚到之前的版本，减少系统 downtime，提高运维效率。

这一功能使 sfsEdgeStore 成为一个真正的企业级软件，区别于普通的开源工具，为用户提供了更专业、更可靠的配置管理体验。
