## 流程说明

1. **消息发送**：
   - mosquitto.exe 发送 EdgeX 格式的消息到 MQTT Broker
   - 消息主题格式：`edgex/events/device/{deviceName}/{resourceName}`

2. **消息接收**：
   - MQTT Broker 接收消息并转发给订阅该主题的客户端
   - sfsEdgeStore MQTT 客户端接收消息

3. **消息处理**：
   - `messageHandler` 函数被触发，处理接收到的消息
   - 调用 `edgex.ProcessMessage` 函数解析消息内容
   - 解析为 `EdgeXMessage` 格式，检查 `MessageType` 是否为 "event"
   - 解析 `Payload` 为 `EdgeXEvent` 格式

4. **设备管理**：
   - 检查设备是否被允许发送数据（根据许可证类型限制设备数量）
   - 注册新设备并记录设备数量

5. **数据处理**：
   - 处理每个读数（Reading）
   - 解析值的类型
   - 更新设备状态
   - 数据过滤
   - 准备存储数据

6. **数据存储**：
   - 批量存储到数据库
   - 使用重试机制处理存储失败
   - 分析错误类型并进行相应处理
   - 将失败的数据加入队列

7. **数据分析**：
   - 对存储的数据进行分析
   - 检测异常和告警
   - 处理分析结果和告警
   - 触发监控告警

## 关键函数调用链

1. `mqtt.NewClient` → 创建 MQTT 客户端
2. `client.Subscribe` → 订阅主题
3. `client.subscribeTopics` → 具体订阅逻辑
4. `client.messageHandler` → 消息处理回调
5. `edgex.ProcessMessage` → 消息解析
6. `client.isDeviceAllowed` → 设备限制检查
7. `database.BatchInsertWithRetry` → 批量存储数据
8. `client.analyzer.Analyze` → 数据分析
