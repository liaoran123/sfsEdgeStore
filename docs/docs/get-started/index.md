# sfsEdgeStore

**Lightweight Industrial IoT Edge Data Storage Adapter**

sfsEdgeStore is a high-performance, low-memory adapter that bridges EdgeX Foundry IoT data with sfsDb (embedded LevelDB) for efficient edge storage.

## Key Features

- **Ultra-Low Memory**: Less than 50MB RAM usage
- **High Reliability**: Automatic retry, queue buffering, data persistence
- **EdgeX Integration**: Seamless MQTT subscription and data parsing
- **Web Dashboard**: Real-time monitoring and device management
- **License Tiers**: Community (free), Business, and Enterprise editions
